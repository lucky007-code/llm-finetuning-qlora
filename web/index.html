Completion-Only Loss Masking Engine

DataCollatorForCompletionOnlyLM

To prevent the model from wasting capacity memorizing prompt tokens, PyTorch cross-entropy loss assigns label = -100 (ignore_index) to prompt tokens and only computes gradients on the model's output tokens.
